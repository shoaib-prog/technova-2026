# ⚡ TechNova 2026

> **Where Innovation Meets Technology**

TechNova 2026 is a multi-page college technical fest website built using **HTML5**. The project simulates an official technical festival website with event information, schedules, participant registration, gallery, team details, FAQs, and contact information.

## 🌐 Project Overview

TechNova 2026 brings together students, developers, innovators, and technology enthusiasts through a collection of technical competitions and activities.

The website focuses on creating a complete multi-page experience using **HTML5 and semantic HTML**.

## ✨ Features

* 🏠 Official landing/home page
* 💻 Technical event catalogue
* 📅 Complete event schedule
* 📝 Participant registration form
* 📸 Event gallery
* 👥 Organizing team section
* ❓ Frequently Asked Questions
* 📍 Contact and venue information
* 🌐 Internal multi-page navigation
* 🎥 Embedded multimedia content
* 📋 HTML tables
* 📝 HTML forms with multiple input types
* 🔗 External, email and telephone links
* ♿ Semantic HTML structure

## 📄 Pages
